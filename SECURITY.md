# Security policy

This library sits in the path of what a voice agent says, so a way to get blocked content spoken
anyway counts as a security issue.

Please don't open a public issue for security problems. Report them privately through
[GitHub security advisories](https://github.com/Apoorv012/pipecat-guardrails/security/advisories/new).
Expect a first reply within 7 days.

Only the latest release gets security fixes.
